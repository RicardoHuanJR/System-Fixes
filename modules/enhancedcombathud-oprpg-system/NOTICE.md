# Notice

Este pacote é um adaptador OPRPG independente que usa a API pública do Argon Core. O Argon Core 5.0.1 não é modificado pelo adaptador.

A integração OPRPG 6.1 usa Activities e estruturas do sistema `oprpg-system` e mantém fallbacks compatíveis com OPRPG 1.0.20 e com as correções locais 1.0.21-local.x.
